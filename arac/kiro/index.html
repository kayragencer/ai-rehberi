Amazon'un (AWS) önce plan yazıp sonra kodlayan yapay zeka kod editörü ve CLI'ı. Kalıcı ücretsiz planda ayda 50 kredi ve Claude Sonnet ile açık modellere sınırlı erişim var, kart istemiyor. Öğrencilere bazı üniversitelerde 1 yıl ücretsiz Pro veriliyor.

3 adımda kullanım

  1. kiro.dev adresinden Kiro'yu indir.
  2. Google, GitHub ya da AWS Builder ID ile giriş yap.
  3. Yapmak istediğini Türkçe anlat; Kiro önce plan çıkarır, sonra kodlar.
